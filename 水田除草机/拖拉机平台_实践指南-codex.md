# 拖拉机智能控制平台（首月可演示版）实践笔记

> 日期：2026-03-03  
> 目标：1个月内产出“稳定可重复”的演示机，优先跑通，不追求量产成熟度

## 1. 已确定方向（不再摇摆）

- 演示主线：水田机器人闭环
- 交互形态：先非触摸中控（OLED + EC11/按键）
- 调度方案：超级循环 + 时基（不在首月上RTOS）
- 验收口径：稳定可重复优先
- CAN深度：协议先行 + 模拟节点
- 硬件策略：允许几百元级小额增购
- 大小脑策略：首月只预留接口，不接Linux大脑

## 2. 首月交付目标（2026-03-03 ~ 2026-04-03）

- 完成水面迷你机器人实机演示闭环
- 支持手动/半自动/自动模式切换
- 具备避障、急停、故障降级、状态可视化
- 形成可重复的30分钟领导演示流程（可连跑3次）

## 3. 范围控制

### 3.1 In（首月必须做）

- 中控菜单收敛到演示闭环
- 运动控制闭环（直行保持 + 基础避障）
- 急停与故障处理
- CAN协议与模拟链路
- 演示脚本与参数冻结

### 3.2 Out（首月不做）

- 量产合规与功能安全认证
- 真触摸大屏完整UI
- 多节点实网CAN联调
- 全面RTOS化
- Linux视觉导航实装

## 4. 四周执行节奏

### 第1周：基线可运行

- 收敛单一电机驱动路径（避免多实现混用）
- 固定一套IMU链路 + 一套TOF链路
- 做启动自检页、故障码显示
- 打通手动控制模式

验收：

- 冷启动成功率 > 95%
- 手动模式连续运行10分钟稳定

### 第2周：稳定控制

- 固定调度节拍：1ms/10ms/50ms/100ms
- 实现航向保持（Assist模式）
- 接入急停、异常保护、恢复策略

验收：

- 航向误差可控
- 急停触发到电机断驱动 < 100ms
- 连续运行20分钟

### 第3周：自动巡航演示

- 实现保守扫掠策略：分段直行 + 定角转向 + TOF触发绕障/回退
- 菜单支持模式切换与关键状态显示

验收：

- 自动模式可稳定运行15分钟
- 避障触发后可恢复任务

### 第4周：演示封装

- 冻结参数与演示版本
- CAN协议联调（模拟节点）
- 完成演示SOP与故障预案

验收：

- 按脚本完成30分钟演示，3次重复通过

## 5. 实现规则（首月固定）

- 调度：超级循环 + 软时基
- 模式机：`MANUAL` / `ASSIST` / `AUTO_SWEEP` / `E_STOP`
- 优先级：`E_STOP > 硬故障 > 避障 > 运动指令`
- 自动算法：只用保守扫掠，不做全局最优覆盖

## 6. 接口预留（为中期/远期避免返工）

建议新增统一类型与接口：

```c
typedef enum { MODE_MANUAL, MODE_ASSIST, MODE_AUTO_SWEEP, MODE_ESTOP } platform_mode_t;
typedef struct { float yaw_deg; uint16_t tof_mm; uint8_t imu_ok; uint8_t tof_ok; } sensor_snapshot_t;
typedef struct { int16_t left_pwm; int16_t right_pwm; uint8_t brake; } motion_cmd_t;
typedef struct { uint8_t estop; uint8_t obstacle; uint8_t fault_code; } safety_state_t;
```

CAN最小报文（先模拟）：

- `0x101`：心跳/模式/故障码
- `0x102`：传感器摘要（yaw、tof、电压）
- `0x201`：外部控制命令（模式切换、速度上限、急停）

## 7. 测试与验收场景清单

- 台架：上电、自检、模式切换、急停、恢复
- 水池：手动、直行保持、避障、自动模式
- 异常：TOF断连、IMU异常、遥控失联、低压模拟
- 回归：按SOP连跑3次，每次30分钟

每次测试记录：

- 通过项
- 失败项
- 风险项
- 下一步动作

## 8. 必须后续偿还的技术债

1. 首月不上RTOS，任务隔离和时序鲁棒性有限（中期必须补）
2. 软I2C与引脚复用冲突，扩展性差（中期板级/总线规划时处理）
3. CAN仅模拟，缺真实总线容错（中期实网前必须补齐）
4. 参数管理与日志体系不完整（首月后第一迭代补）
5. 缺量产级安全链路（进量产评估前必须重做）

## 9. 中长期演进一句话

- 中期：中控节点 + 执行节点 + 传感节点的CAN架构
- 远期：Linux大脑（导航/视觉/规划） + MCU小脑（实时控制/安全）
- 首月策略：先把“小脑可演示闭环”做扎实，再扩到大小脑协同
