# 水田除草机路径规划算法设计方案

## 1. 算法概述

本方案设计了一种基于"弓字形"（Boustrophedon）路径的矩形水田全覆盖算法。机器在水田中按照平行往返路线行驶，碰到边界后旋转180度继续下一行，确保完整遍历整个水田面积。

### 1.1 核心特点
- **全覆盖保证**：通过规则的往返路径确保无遗漏区域
- **高效性**：最小化转向次数，减少重复覆盖
- **鲁棒性**：基于传感器实时检测边界，适应不规则田埂
- **可验证性**：通过覆盖率网格实时监控作业进度

## 2. 路径规划算法

### 2.1 算法类型：弓字形路径（Boustrophedon Path）

```
起点 →→→→→→→→→→ 边界
         ↓ 转向180°
边界 ←←←←←←←←←←
         ↓ 转向180°
     →→→→→→→→→→ 边界
         ↓ 转向180°
边界 ←←←←←←←←←←
         ↓
        ...
```

### 2.2 算法状态机

```c
typedef enum {
    STATE_FORWARD,      // 直线前进
    STATE_DETECT_EDGE,  // 检测到边界
    STATE_TURN_180,     // 执行180度转向
    STATE_SHIFT_ROW,    // 横向平移一个作业宽度
    STATE_COMPLETED     // 作业完成
} PathState;
```

### 2.3 核心参数

| 参数名称 | 说明 | 推荐值 |
|---------|------|--------|
| `WORK_WIDTH` | 除草机作业宽度 | 0.5m - 0.8m |
| `FORWARD_SPEED` | 前进速度 | 0.3 - 0.5 m/s |
| `TURN_SPEED` | 转向速度 | 0.2 m/s |
| `EDGE_THRESHOLD` | 边界检测距离阈值 | 15 - 30 cm |
| `ROW_OVERLAP` | 行间重叠率 | 10% - 15% |

## 3. 算法实现逻辑

### 3.1 主控制流程

```c
void path_planning_task(void) {
    static PathState state = STATE_FORWARD;
    static uint8_t row_count = 0;
    static float current_heading = 0.0f;  // 当前航向角

    switch(state) {
        case STATE_FORWARD:
            // 直线前进
            move_forward(FORWARD_SPEED);

            // 检测前方边界
            if (detect_front_edge()) {
                state = STATE_DETECT_EDGE;
                stop_motors();
            }
            break;

        case STATE_DETECT_EDGE:
            // 记录当前位置
            record_position();

            // 判断是否完成所有行
            if (is_field_completed()) {
                state = STATE_COMPLETED;
            } else {
                state = STATE_TURN_180;
            }
            break;

        case STATE_TURN_180:
            // 执行180度原地转向
            if (turn_in_place(180.0f)) {
                row_count++;
                state = STATE_SHIFT_ROW;
            }
            break;

        case STATE_SHIFT_ROW:
            // 横向平移一个作业宽度
            if (shift_lateral(WORK_WIDTH)) {
                state = STATE_FORWARD;
                update_coverage_map();
            }
            break;

        case STATE_COMPLETED:
            stop_motors();
            report_completion();
            break;
    }
}
```

### 3.2 边界检测函数

```c
bool detect_front_edge(void) {
    uint16_t distance_left = vl53l0x_read_distance(SENSOR_LEFT);
    uint16_t distance_center = vl53l0x_read_distance(SENSOR_CENTER);
    uint16_t distance_right = vl53l0x_read_distance(SENSOR_RIGHT);

    // 任意一个传感器检测到边界
    if (distance_left < EDGE_THRESHOLD ||
        distance_center < EDGE_THRESHOLD ||
        distance_right < EDGE_THRESHOLD) {
        return true;
    }
    return false;
}
```

### 3.3 180度转向函数

```c
bool turn_in_place(float target_angle) {
    static float start_heading = 0.0f;
    static bool turn_started = false;

    if (!turn_started) {
        start_heading = imu_get_heading();  // 获取初始航向
        turn_started = true;
    }

    float current_heading = imu_get_heading();
    float turned_angle = normalize_angle(current_heading - start_heading);

    if (fabs(turned_angle - target_angle) < 5.0f) {  // 5度误差容限
        stop_motors();
        turn_started = false;
        return true;  // 转向完成
    }

    // 原地转向：左右轮反向旋转
    Motor_Set(1, TURN_SPEED);   // 左前
    Motor_Set(2, -TURN_SPEED);  // 左后
    Motor_Set(3, TURN_SPEED);   // 右前
    Motor_Set(4, -TURN_SPEED);  // 右后

    return false;  // 转向未完成
}
```

### 3.4 横向平移函数

```c
bool shift_lateral(float distance) {
    static float start_position = 0.0f;
    static bool shift_started = false;

    if (!shift_started) {
        start_position = get_lateral_position();  // 获取初始横向位置
        shift_started = true;
    }

    float current_position = get_lateral_position();
    float shifted_distance = fabs(current_position - start_position);

    if (shifted_distance >= distance * (1.0f - ROW_OVERLAP)) {
        stop_motors();
        shift_started = false;
        return true;  // 平移完成
    }

    // 横向移动（根据当前航向调整）
    move_lateral(FORWARD_SPEED * 0.5f);

    return false;  // 平移未完成
}
```

## 4. 覆盖率验证方法

### 4.1 网格地图法

将水田划分为网格，每个网格代表一个小区域（如0.1m × 0.1m）。机器经过时标记该网格为已覆盖。

```c
#define GRID_SIZE 0.1f  // 网格尺寸 10cm
#define MAX_GRID_X 100  // 最大10m宽
#define MAX_GRID_Y 100  // 最大10m长

typedef struct {
    uint8_t coverage_map[MAX_GRID_X][MAX_GRID_Y];  // 0=未覆盖, 1=已覆盖
    float field_width;   // 水田宽度
    float field_length;  // 水田长度
    uint32_t total_grids;
    uint32_t covered_grids;
} CoverageMap;

CoverageMap coverage;
```

### 4.2 实时更新覆盖地图

```c
void update_coverage_map(void) {
    // 获取当前位置
    float x = get_current_x();
    float y = get_current_y();

    // 转换为网格坐标
    int grid_x = (int)(x / GRID_SIZE);
    int grid_y = (int)(y / GRID_SIZE);

    // 标记作业宽度范围内的网格
    int work_grids = (int)(WORK_WIDTH / GRID_SIZE);
    for (int i = -work_grids/2; i <= work_grids/2; i++) {
        int gx = grid_x + i;
        if (gx >= 0 && gx < MAX_GRID_X && grid_y >= 0 && grid_y < MAX_GRID_Y) {
            if (coverage.coverage_map[gx][grid_y] == 0) {
                coverage.coverage_map[gx][grid_y] = 1;
                coverage.covered_grids++;
            }
        }
    }
}
```

### 4.3 覆盖率计算

```c
float calculate_coverage_rate(void) {
    if (coverage.total_grids == 0) return 0.0f;
    return (float)coverage.covered_grids / coverage.total_grids * 100.0f;
}

bool is_field_completed(void) {
    float coverage_rate = calculate_coverage_rate();
    return (coverage_rate >= 95.0f);  // 95%覆盖率视为完成
}
```

### 4.4 可视化验证（可选）

```c
void display_coverage_map(void) {
    // 在LCD屏幕上显示覆盖地图
    for (int y = 0; y < MAX_GRID_Y; y++) {
        for (int x = 0; x < MAX_GRID_X; x++) {
            uint16_t color = coverage.coverage_map[x][y] ? GREEN : RED;
            LCD_DrawPoint(x, y, color);
        }
    }

    // 显示覆盖率百分比
    char buf[32];
    sprintf(buf, "Coverage: %.1f%%", calculate_coverage_rate());
    LCD_ShowString(0, 0, buf);
}
```

## 6. 旋转角度策略

### 6.1 转向角度设计

| 场景 | 旋转角度 | 说明 |
|------|---------|------|
| **行末转向** | 180° | 原地转向，准备返回下一行 |
| **避障微调** | ±5° - ±15° | 检测到斜向边界时微调航向 |
| **初始对齐** | 0° - 360° | 启动时对齐到水田长边方向 |

### 6.2 转向方式

#### 6.2.1 原地转向（Zero-radius Turn）
```c
// 左右轮反向旋转，转向半径为0
void turn_in_place_left(float speed) {
    Motor_Set(1, -speed);  // 左前轮后退
    Motor_Set(2, -speed);  // 左后轮后退
    Motor_Set(3, speed);   // 右前轮前进
    Motor_Set(4, speed);   // 右后轮前进
}
```

**优点**：转向空间小，适合狭窄田埂边缘
**缺点**：对地面摩擦力要求高，可能打滑

#### 6.2.2 差速转向（Differential Turn）
```c
// 一侧轮速度降低，另一侧保持
void turn_differential_left(float speed, float turn_ratio) {
    float left_speed = speed * (1.0f - turn_ratio);
    float right_speed = speed;

    Motor_Set(1, left_speed);
    Motor_Set(2, left_speed);
    Motor_Set(3, right_speed);
    Motor_Set(4, right_speed);
}
```

**优点**：转向平滑，不易打滑
**缺点**：需要更大的转向空间

### 6.3 转向精度控制

```c
#define TURN_TOLERANCE 5.0f  // 转向误差容限 ±5度

// PID控制转向角度
typedef struct {
    float kp;
    float ki;
    float kd;
    float integral;
    float last_error;
} PID_Controller;

float pid_turn_control(PID_Controller *pid, float target_angle, float current_angle) {
    float error = normalize_angle(target_angle - current_angle);

    pid->integral += error;
    float derivative = error - pid->last_error;

    float output = pid->kp * error + pid->ki * pid->integral + pid->kd * derivative;

    pid->last_error = error;

    // 限制输出范围
    if (output > MAX_TURN_SPEED) output = MAX_TURN_SPEED;
    if (output < -MAX_TURN_SPEED) output = -MAX_TURN_SPEED;

    return output;
}
```

```c
// 保存作业进度到EEPROM
void save_progress(void) {
    Progress progress;
    progress.row_count = current_row;
    progress.coverage_rate = calculate_coverage_rate();
    progress.position_x = get_current_x();
    progress.position_y = get_current_y();

// 恢复作业进度
void resume_progress(void) {
    Progress progress;
    eeprom_read(&progress, sizeof(Progress));

    // 导航到上次位置
    navigate_to(progress.position_x, progress.position_y);
    current_row = progress.row_count;
}
```

## 9. 故障处理机制

### 9.1 传感器故障

```c
void sensor_fault_detection(void) {
    // VL53L0X传感器故障检测
    if (vl53l0x_check_timeout()) {
        // 降级模式：仅使用IMU和编码器
        enable_degraded_mode();
        alert_user(SENSOR_FAULT);
    }

    // IMU传感器故障检测
    if (imu_check_data_valid() == false) {
        stop_motors();
        alert_user(IMU_FAULT);
    }
}
```

### 9.2 卡住检测

```c
void stuck_detection(void) {
    static uint32_t last_position_time = 0;
    static float last_x = 0, last_y = 0;

    float current_x = get_current_x();
    float current_y = get_current_y();

    // 5秒内位置变化小于10cm
    if (get_time_ms() - last_position_time > 5000) {
        float distance_moved = sqrt(pow(current_x - last_x, 2) + pow(current_y - last_y, 2));

        if (distance_moved < 0.1f) {
            // 执行脱困动作
            execute_unstuck_maneuver();
        }

        last_x = current_x;
        last_y = current_y;
        last_position_time = get_time_ms();
    }
}
```
