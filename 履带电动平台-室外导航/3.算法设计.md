## 二、驱动层功能需求

### DRV-001 超声波阵列驱动

**功能简述**：驱动5路HC-SR04超声波传感器，实现轮询触发、输入捕获、数据滤波，输出稳定距离值。

**硬件连接**：
- 触发信号：PC0-PC8（5路GPIO输出）
- 回波信号：TIM2_CH1-CH4（4路捕获），TIM3_CH1（1路捕获，复用）

**输入**：
- 无（硬件触发）

**输出**：
```c
typedef struct {
    float distance[5];      // 单位：cm，范围2-400，无效值-1
    bool valid[5];          // 数据有效性
    uint32_t timestamp;     // 更新时间戳
} UltraOutput_t;
```

**关键要求**：
1. **触发时序**：5路轮流触发，间隔10ms，避免串扰
2. **测量频率**：每路20Hz，总周期50ms
3. **滤波算法**：中值滤波（5点滑动窗口）+ 异常值剔除（与上次偏差>20cm则丢弃）
4. **超时处理**：30ms无回波视为超时，标记无效
5. **温度补偿**：声速按343m/s（20℃），后续做温度补偿

**验收标准**：
- 精度测试：30cm标准障碍物，100次测量标准差<1cm
- 响应延迟：从触发到输出结果<15ms
- 并发测试：5路同时工作，误触发率<1%

### DRV-002 GPS驱动

**功能简述**：解析NEO-6M/ATGM336H NMEA数据，输出经纬度、速度、航向、定位质量。

**硬件连接**：
- USART1，波特率9600，DMA接收

**输入**：
- NMEA语句（$GPGGA, $GPRMC等）

**输出**：
```c
typedef struct {
    double latitude;        // 纬度，度
    double longitude;       // 经度，度
    float altitude;         // 海拔，m
    float speed;            // 地面速度，m/s
    float course;           // 地面航向，度（正北为0，顺时针）
    uint8_t fix_quality;    // 0=无效，1=GPS定位，2=DGPS
    uint8_t num_sats;       // 卫星数
    float hdop;             // 水平精度因子
    bool valid;             // 整体有效性（fix_quality>0且hdop<10）
    uint32_t timestamp;     // 系统时间戳
} GPSOutput_t;
```

**关键要求**：
1. **解析频率**：原始数据5Hz，输出5Hz
2. **数据超时**：2秒未收到有效数据，valid置false
3. **坐标转换**：提供WGS84转局部坐标函数（墨卡托投影）
4. **启动配置**：上电自动配置为5Hz输出，只发GGA和RMC语句

**验收标准**：
- 开阔场地定位精度<3m（CEP50）
- 从冷启动到定位<45秒
- 数据更新延迟<200ms

**PID参数**（需现场整定）：
- Kp=1.0, Ki=0.1, Kd=0.01

**验收标准**：

## 三、算法层功能需求

### ALG-001 障碍物检测融合

**功能简述**：融合5路超声波数据，构建车身周围障碍物地图，区分动静，预测碰撞风险。

**输入**：
- UltraOutput_t（5路距离）
- 当前车速v（m/s）
- 当前角速度omega（rad/s）

**输出**：
```c
typedef struct {
    float obstacle_x[16];     // 障碍物X坐标（车体坐标系，m）
    float obstacle_y[16];     // 障碍物Y坐标（车体坐标系，m）
    uint8_t obstacle_num;     // 障碍物数量
    float nearest_dist;       // 最近障碍物距离（m）
    float nearest_angle;      // 最近障碍物角度（度）
    bool collision_risk;      // 2秒内碰撞风险
    float risk_time;          // 预计碰撞时间（s）
} ObstacleFusionOutput_t;
```

**算法逻辑**：
1. **坐标转换**：每路超声波距离转车体坐标（考虑安装位置偏移）
2. **数据关联**：新测量与已有障碍物匹配（距离<0.5m视为同一目标）
3. **卡尔曼滤波**：更新障碍物位置、速度估计
4. **动静分类**：速度>0.3m/s标记为动态，否则静态
5. **碰撞检测**：预测2秒后**车辆包络**与障碍物是否重叠

**关键参数**：
- 车辆包络：长0.8m×宽0.5m，前后各留0.3m安全距离
- 传感器布局：
  - U0（左前）：x=0.3, y=0.15, angle=30°
  - U1（正前）：x=0.35, y=0, angle=0°
  - U2（右前）：x=0.3, y=-0.15, angle=-30°
  - U3（左后）：x=-0.3, y=0.15, angle=150°
  - U4（右后）：x=-0.3, y=-0.15, angle=-150°

**验收标准**：
- 静态障碍物定位精度：±10cm（距离<2m时）
- 碰撞预测准确率：>90%（TPR），误报率<10%（FPR）
- 计算耗时：<5ms（20Hz运行）

### ALG-002 多传感器定位

**功能简述**：融合GPS、编码器、可选IMU，输出高精度位姿（位置+航向）。

**输入**：
- GPSOutput_t
- 编码器：左右轮累计距离（m）
- IMU（可选）：yaw角（度），角速度（dps）

**输出**：
```c
typedef struct {
    double x;               // 东向位置（m，局部坐标系）
    double y;               // 北向位置（m，局部坐标系）
    float theta;            // 航向角（度，正北为0，顺时针）
    float v;                // 线速度（m/s）
    float omega;            // 角速度（rad/s）
    uint8_t quality;        // 定位质量0-100（基于协方差）
    bool gps_valid;         // GPS当前是否有效
    uint32_t timestamp;
} LocalizationOutput_t;
```

**算法逻辑**：
1. **EKF预测**：编码器推算位置（运动学模型）
2. **EKF更新**：GPS有效时校正位置，GPS无效时纯推算
3. **航向融合**：GPS航向（运动时有效）+ 编码器推算（差速计算）+ IMU积分
4. **原点设置**：上电时当前位置设为(0,0)，航向可通过GPS或手动设定

**关键参数**：
- 过程噪声：位置0.01m?0?5，航向0.001rad?0?5
- GPS观测噪声：位置4m?0?5（根据hdop动态调整），航向0.1rad?0?5
- 编码器：每米脉冲数需标定

**验收标准**：
- GPS良好时定位精度：±30cm
- GPS丢失10秒后精度：±1m（编码器推算）
- 航向精度：±5度（GPS良好），±15度（纯推算10秒）

### ALG-003 路径跟踪控制

**功能简述**：根据全局路径和当前位置，计算控制指令（速度+转向），使车辆沿路径行驶。

**输入**：
- LocalizationOutput_t
- 全局路径：Waypoint_t数组（x, y, heading, speed_limit）
- 当前目标点索引

**输出**：
```c
typedef struct {
    float target_v;         // 目标线速度（m/s）
    float target_omega;     // 目标角速度（rad/s）
    uint16_t target_idx;    // 当前跟踪的路径点索引
    float cross_track_error; // 横向误差（m，正值偏右）
    float heading_error;    // 航向误差（度）
    float lookahead_dist;   // 当前前视距离（m）
} PathTrackingOutput_t;
```

**算法选择**（二选一，建议Pure Pursuit）：

**方案A：纯追踪（Pure Pursuit）**
1. 根据当前速度计算前视距离：L = 0.5 + 0.5*v（范围0.5-2.0m）
2. 在路径上找距离当前位置L米的前视点
3. 计算曲率：κ = 2*y/L?0?5（y为前视点在车体坐标系的横向偏移）
4. 目标角速度：omega = κ * v

**方案B：Stanley算法**
1. 找最近路径点，计算横向误差e
2. 目标航向 = 路径航向 + arctan(k*e/v)
3. 角速度 = 目标航向 - 当前航向

**关键参数**：
- 最大速度：1.5m/s（直线），0.8m/s（转弯）
- 横向误差容忍：±20cm，超出减速
- 到达判断：距离终点<0.5m且航向误差<15度

**验收标准**：
- 直线跟踪：横向误差RMS<5cm
- 转弯跟踪：横向误差RMS<15cm
- 稳定速度：±0.1m/s波动

### ALG-004 局部避障规划

**功能简述**：检测到障碍物时，实时规划绕行轨迹，或减速停车等待。

**输入**：
- LocalizationOutput_t
- ObstacleFusionOutput_t
- 全局路径目标点

**输出**：
```c
typedef struct {
    float cmd_v;            // 指令速度（m/s，可能为0或负值后退）
    float cmd_omega;        // 指令角速度（rad/s）
    uint8_t action;         // 0=正常，1=减速，2=停车等待，3=绕行，4=后退
    uint32_t plan_duration; // 该指令有效期（ms）
} LocalPlannerOutput_t;
```

**算法逻辑（动态窗口法DWA）**：
1. **速度空间采样**：v∈[0, 1.5]，omega∈[-1, 1]，离散化为10×15网格
2. **轨迹模拟**：每个(v, omega)组合模拟2秒轨迹，检查碰撞
3. **评价函数**：
   - heading_cost：与目标方向偏差（权重2.0）
   - dist_cost：与障碍物距离（权重1.0，<0.3m直接淘汰）
   - velocity_cost：鼓励高速（权重0.5）
   - goal_cost：接近目标奖励（权重1.0）
4. **选择最优**：总分最高的可行轨迹

**简化方案（向量场直方图VFH）**：
- 构建36扇区（每扇区10度）障碍物密度直方图
- 找与目标方向最接近且密度低于阈值的扇区
- 直接输出转向指令（适合算力有限场景）

**关键参数**：
- 车辆包络：长0.8m，宽0.5m，安全边界0.3m
- 预测时域：2秒
- 最小通过宽度：1.2m（车身+两侧各0.2m余量）

**验收标准**：
- 静态避障成功率：>95%（障碍物间距>1.5m时）
- 动态避障：检测到移动障碍物，2秒内减速停车
- 计算耗时：<10ms（10Hz运行）

**验收标准**：
- 路线加载时间：<100ms

### TASK-002 通信协议栈 CAN？

**功能简述**：定义无线遥控、4G上报、调试接口的数据帧格式。

**帧格式（统一）**：
```
[帧头0xAA][帧头0x55][长度1B][类型1B][载荷N B][CRC16 2B]
```

**类型定义**：
- 0x01：遥控指令（速度+模式）
- 0x02：状态上报（位置+速度+电量）
- 0x03：路径下发（路径点序列）
- 0x04：参数配置（PID/限速等）
- 0x05：心跳帧
- 0xFF：调试命令

**关键要求**：
1. **CRC校验**：Modbus CRC16，错误帧丢弃
2. **重传机制**：重要指令（如急停）需ACK，超时重传3次
3. **版本兼容**：帧头包含协议版本号，便于升级

### APP-002 自动驾驶模式

**功能简述**：一键启动，车辆沿预定义路线从A点自动驾驶到B点。

**执行流程**：
1. **自检**：检查GPS、超声波、电机状态，异常则拒绝启动
2. **定位**：找当前位置在路径上的最近点，设为起点
3. **启动**：提示"即将启动，请避让"，3秒后起步
4. **行驶**：循环执行：定位→感知→规划→控制→上报

6. **异常处理**：
   - 障碍物阻挡>10秒：播报"等待障碍物移除"
   - GPS丢失>30秒：播报"定位异常，请求人工接管"

- LED状态灯：蓝色=遥控，绿色=自动，红色=故障，黄色=等待
- 蜂鸣器：启动前3秒提示，异常时连续蜂鸣
- 语音播报（可选）：通过4G模块TTS或外接喇叭

```c
// Cdd_Ultra_Safety.c
#include "Cdd_Ultra.h"

// 安全监控：数据时效性检查
#define ULTRA_DATA_TIMEOUT_MS   100U   // 100ms无数据视为失效
#define ULTRA_PLAUSIBILITY_CHECK  1     // 使能合理性检查

// 冗余采样：两次触发验证
typedef struct {
    float distance_sample1;
    float distance_sample2;
    float distance_final;
    bool consistency;           // 一致性标志
} Ultra_SafetyDataType;

// 合理性检查范围（根据安装位置）
static const float ULTRA_MIN_DIST[5] = {2.0f, 2.0f, 2.0f, 2.0f, 2.0f};
static const float ULTRA_MAX_DIST[5] = {400.0f, 400.0f, 400.0f, 200.0f, 200.0f};

// 安全处理函数
Std_ReturnType Cdd_Ultra_SafetyCheck(uint8_t channel, Ultra_SafetyDataType* safetyData)
{
    // 1. 时效性检查
    if((GetTick() - lastUpdate[channel]) > ULTRA_DATA_TIMEOUT_MS) {
        Dem_ReportErrorStatus(ULTRA_E_TIMEOUT, DEM_EVENT_STATUS_FAILED);
        return E_NOT_OK;
    }
    
    // 2. 冗余采样一致性检查（两次采样偏差<5%）
    float diff = fabs(safetyData->distance_sample1 - safetyData->distance_sample2);
    float avg = (safetyData->distance_sample1 + safetyData->distance_sample2) / 2.0f;
    
    if((diff / avg) > 0.05f) {
        // 不一致，使用保守值（较小值）
        safetyData->distance_final = fmin(safetyData->distance_sample1, 
                                          safetyData->distance_sample2);
        safetyData->consistency = FALSE;
        Dem_ReportErrorStatus(ULTRA_E_INCONSISTENT, DEM_EVENT_STATUS_PREFAILED);
    } else {
        safetyData->distance_final = avg;
        safetyData->consistency = TRUE;
    }
    
    // 3. 合理性范围检查
    if(safetyData->distance_final < ULTRA_MIN_DIST[channel] || 
       safetyData->distance_final > ULTRA_MAX_DIST[channel]) {
        Dem_ReportErrorStatus(ULTRA_E_RANGE, DEM_EVENT_STATUS_FAILED);
        return E_NOT_OK;
    }
    
    return E_OK;
}
```

### 项目标题
**基于AUTOSAR Classic Platform的园区自动驾驶域控制器MCU软件开发**

### 技术亮点
1. **AUTOSAR架构设计**：独立完成MCAL、ECU抽象层、服务层配置，实现超声波CDD复杂驱动和电机PWM标准驱动，通过RTE接口实现SWC组件解耦

2. **功能安全开发**：按照ISO26262-6标准，完成HARA分析、SFMEA、FTA、DFA，针对超声波避障功能实现ASIL-B等级，包括数据时效性监控、冗余采样一致性检查、看门狗安全监控

3. **车规通信协议栈**：实现UDS诊断服务（0x10/0x22/0x2E/0x31），支持DTC故障码管理；集成XCP标定协议，完成A2L文件配置，支持PID参数在线标定

4. **多传感器融合**：基于扩展卡尔曼滤波实现编码器+GPS融合定位，设计动态窗口法（DWA）局部避障算法，纯追踪算法路径跟踪，横向误差RMS<5cm

5. **ASPICE流程实践**：建立需求追溯矩阵（Req-Design-Code-Test），完成单元测试（Tessy）、SIL测试，输出软件需求规范（SRS）、软件架构设计（SWAD）
