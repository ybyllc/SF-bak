# E34-2G4D27D 新手速通
4. A 端串口发什么，B 端串口就收到什么（透明传输）

## 接线

1. 接线：
- `VCC` 接电源（2.3~5.5V）
- `GND` 共地
- `模块RXD <- 主控TXD`
- `模块TXD -> 主控RXD`
- `AUX`：忙闲指示（高=可操作）默认不接
- `M0/M1`：选模式

### 模式一览

- 模式 0：`M1=0 M0=0`，透明传输（半双工）
- 模式 1：`M1=0 M0=1`，透明传输（全双工）
- 模式 2：`M1=1 M0=0`，预留
- 模式 3：`M1=1 M0=1`，设置

### 配对方法（必须看）

两模块要配对（出厂默认都配对）
- 波特率一样（`SPED`） 默认 9600
- 信道一样（`CHAN`） 默认 0000
- 地址一样（`ADDH/ADDL`） 默认 0


## 设置命令（在`M1=1 M0=1`设置模式，串口 9600）

- 读取当前参数：`C1 C1 C1`
- 读版本：`C3 C3 C3`
- 复位：`C4 C4 C4`
- 写参数并保存：`C0 + 5字节`
- 写参数不保存：`C2 + 5字节`

默认参数：

`C0 00 00 18 00 40`
C0默认 00 00地址 18波特率 00信道 40发射功率最大

### 波特率速查（SPED）

- 9600：`18`（默认）
- 19200：`20`
- 38400：`28`
- 57600：`30`
- 115200：`38`

示例：
9600命令：`C0 00 00 18 00 40`
115200命令：`C0 00 00 38 00 40`
（地址 0000，信道 00，9600）
