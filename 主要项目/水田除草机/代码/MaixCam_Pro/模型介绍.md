# 水瓶追踪版本选择说明（v1~v4）

本文用于帮助用户在 `yolo11_detect_v1.py` ~ `yolo11_detect_v4.py` 中快速选型。

## 1. 一句话结论

- 追求最稳、最容易和下位机联调：优先 `v4`
- 追求更“平滑”的跟踪手感（卡尔曼参与更深）：优先 `v2`
- 想要最简单、最容易读懂：用 `v1`

## 2. 各版本定位

## v1（基础检测版）

- 特点：YOLO 检测后直接发目标偏移，不做卡尔曼跟踪
- 优点：逻辑最简单，便于调试
- 缺点：抖动较明显，遮挡后稳定性一般
- 适用：初次联调、验证串口协议

## v2（卡尔曼深度参与版）

- 特点：内置 `KalmanFilter2D`，检测与预测结合较紧
- 优点：轨迹更平滑，速度估计/轨迹可视化更完整
- 缺点：状态机更复杂，对参数更敏感
- 适用：对“平滑跟踪”要求高的场景

## v3（工程化过渡版）

- 特点：卡尔曼拆到独立模块 `kalman.py`，目标打分更综合
- 优点：结构更清晰，便于维护
- 缺点：与 v4 相比收益不明显
- 适用：需要模块化但不追求最新版细节时

## v4（最终优化版）

- 特点：综合目标打分（置信度+连续性+居中+面积过滤）
- 优点：遮挡/干扰下更稳，和下位机联调通常更省心
- 缺点：平滑感不一定比 v2 更“顺手”（取决于场景）
- 适用：默认推荐版本

## 3. 关键差异（算法与通信）

- 检测阈值：
`v1=0.5`，`v2=0.5`，`v3/v4=0.45`
- 预测窗口：
`v1` 无预测；`v2/v3/v4` 有预测（当前 `v2` 为 `500ms`，约 `15` 帧）
- 目标选择策略：
`v1` 偏“最大框”；`v2` 偏“置信度+与预测位置距离”；`v3/v4` 为综合打分
- 串口协议：
四个版本均为 `AA 55 21 CLASS XH XL YH YL FLAG CHECK 0D 0A`

## 4. 推荐选型

- 推荐 A（默认）：`v4`
- 推荐 B（偏平滑）：`v2`
- 推荐 C（教学/调试）：`v1`

## 5. 当前项目备注（2026-03-25）

- `v2` 的通信发送逻辑已对齐到 `v4`（`send_data + flag_map + time.time` 节拍）
- 目的：排除通信层差异，便于只比较算法差异
