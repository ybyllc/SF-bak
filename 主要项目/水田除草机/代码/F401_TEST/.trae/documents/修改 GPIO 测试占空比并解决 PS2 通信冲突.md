## 问题分析
PS2 引脚对应关系：
- PC0 = DAT (输入)
- PC1 = CMD (输出)  
- PC2 = CS (输出)
- PC3 = CLK (输出)

当前 GPIO 测试使用 1,2,3,4 次高电平，但用户需要：
- CLK (PC3): 30% → 3次高/10次
- CS (PC2): 15% → 调整为 1次或2次
- CMD (PC1): 20% → 2次高
- DAT (PC0): 10% → 1次高

## 解决方案

### 1. 修改 GPIO 测试占空比
```c
// 按引脚顺序 PC0,PC1,PC2,PC3 对应 DAT,CMD,CS,CLK
static const uint8_t gpio_pin_high_times[4] = {1, 2, 2, 3};  // DAT:10%, CMD:20%, CS:20%, CLK:30%
```

### 2. 解决 PS2 通信问题
在 GPIO 测试页面添加退出处理：
- 当离开 GPIO 测试页面时，停止 PWM 并将所有引脚设为高电平
- 或者在 PS2 初始化时强制重新配置引脚

建议方案：
在 menu.c 中添加页面切换检测，当从 GPIO_TEST 切换到其他页面时，执行清理操作：
- 设置 gpio_initialized = 0
- 将所有引脚设为高电平

这样 PS2 初始化时会重新配置引脚，确保通信正常。
