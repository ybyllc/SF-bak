## 功能需求

添加 PS2 Control 模式子菜单，实现：

1. 使用 PS2 手柄遥控控制电机 PWM
2. 使用标准电机驱动 motor\_standard
3. 左摇杆控制后电机（MOTOR\_BACK\_LEFT, MOTOR\_BACK\_RIGHT）
4. 右摇杆控制前电机（MOTOR\_FRONT\_LEFT, MOTOR\_FRONT\_RIGHT）
5. 在屏幕上显示摇杆进度条

## 实现方案

### 1. 添加新页面类型

在 menu.h 中添加：

```c
MENU_PAGE_PS2_CONTROL  // PS2控制模式页面
```

### 2. 添加菜单项

在主菜单中添加 "PS2 Control" 项

### 3. 实现 PS2 控制页面函数

创建 `Menu_DisplayPS2ControlPage()` 函数：

* 读取 PS2 手柄数据

* 将摇杆值（0-255）映射到电机速度（-1000 到 1000）

* 左摇杆 Y 轴控制后电机前进/后退

* 右摇杆 Y 轴控制前电机前进/后退

* 在 OLED 上显示：

  * 页面标题

  * 左摇杆进度条（后电机）

  * 右摇杆进度条（前电机）

  * 当前电机速度值

### 4. 摇杆值映射

* 摇杆值 0-255，中点约 128

* 映射公式：speed = (joystick - 128) \* 1000 / 128

* 结果范围：-1000 到 +1000

### 5. 页面退出处理

* 停止所有电机

* 确保安全性

## 修改文件

1. menu.h - 添加新页面类型
2. menu.c - 添加菜单项和页面实现
3. 可能需要修改 menu\_input.c 处理按键
