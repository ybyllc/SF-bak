## 关键设计说明

### 硬件接口分配 (STM32F401RCT6)
| 外设 | 接口 | 备注 |
|------|------|------|
| **5x 超声波** | TIM2_CH1-5 | 输入捕获测距，前3后2布局 |
| **GPS模块** | USART1 (PA9/PA10) | 9600bps, NMEA协议 |
| **4G模块** | USART2 (PA2/PA3) | 115200bps, AT指令 |
| **无线串口** | USART6 (PC6/PC7) | 遥控/调试通道 |
| **左电机驱动** | TIM3_CH1/2 (PA6/PA7) | PWM调速+方向 |
| **右电机驱动** | TIM3_CH3/4 (PB0/ PB1) | PWM调速+方向 |
| **编码器(可选)** | TIM4/TIM5 | 正交编码输入 |
| **SD卡** | SPI1 (PA5-PA7) | 轨迹记录 |
| **蜂鸣器/LED** | GPIO | 状态指示 |

### 5个超声波布局建议
```
      [U1]      [U2]      [U3]      ← 前方120°扇形 (避障主传感器)
         \       |       /
          \      |      /
           [车体中心/GPS天线]
          /      |      \
         /       |       \
      [U4]---------------[U5]      ← 后方两侧 (倒车/防撞)
安装高度: 30-50cm
探测范围: 2cm-400cm
更新频率: 20Hz
```

### 自动驾驶状态机
```c
typedef enum {
    AP_STATE_IDLE = 0,        // 待机
    AP_STATE_INIT,            // 初始化(自检)
    AP_STATE_READY,           // 就绪等待
    AP_STATE_PLANNING,        // 路径规划
    AP_STATE_RUNNING,         // 正常运行
    AP_STATE_AVOIDING,        // 主动避障
    AP_STATE_PAUSED,          // 暂停(临时障碍)
    AP_STATE_ARRIVED,         // 到达目标
    AP_STATE_ERROR            // 故障状态
} AutopilotState_t;
```

### 核心任务优先级 (FreeRTOS)
| 任务 | 优先级 | 周期 | 功能 |
|------|--------|------|------|
| `task_motor_control` | 4 (最高) | 10ms | PID调速,紧急制动 |
| `task_obstacle_detection` | 3 | 50ms | 超声波避障决策 |
| `task_autopilot` | 3 | 50ms | 路径跟踪,转向控制 |
| `task_communication` | 2 | 20ms | 4G/无线数据收发 |
| `task_sensor_acquisition` | 2 | 100ms | GPS/传感器采集 |
| `task_system_monitor` | 1 | 1000ms | 电量/温度/故障检测 |

```c
#define PRIO_MOTOR_CONTROL        4   // 电机控制(最高)
#define PRIO_OBSTACLE_AVOID       3   // 避障检测
#define PRIO_AUTOPILOT            3   // 自动驾驶
#define PRIO_SENSOR_FUSION        2   // 传感器融合
#define PRIO_GPS_PARSER           2   // GPS解析
#define PRIO_COMM_WIRELESS        2   // 无线通信
#define PRIO_COMM_4G              1   // 4G通信
#define PRIO_SYSTEM_MONITOR       1   // 系统监控
#define PRIO_DATA_RECORD          1   // 数据记录
```
